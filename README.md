# basis

Минимальная заготовка проекта для сервиса на PocketBase.

## Цель

Сделать приложение, где:

- админ управляет системой через PocketBase Admin UI;
- пользователи авторизуются по логину и паролю;
- после входа все пользователи видят общий поток обращений;
- пользователь может оставить обращение;
- если в тексте обращения есть слово "привет", категория = 1;
- если слова "привет" нет, категория = 2.

## План по этапам

1. Подготовить проект и git.
2. Поднять PocketBase локально.
3. Описать структуру данных в PocketBase.
4. Настроить авторизацию пользователей.
5. Сделать страницу общего потока обращений.
6. Подготовить деплой на Timeweb Cloud.

## Локальный запуск

1. Запустить PocketBase:

```bash
./scripts/run-pocketbase.sh
```

2. Открыть сайт:

```text
http://127.0.0.1:8090/
```

3. Открыть админку:

```text
http://127.0.0.1:8090/_/
```

## Важные правила

- Исходный код храним в GitHub.
- Локальные данные PocketBase не коммитим в git.
- Все изменения делаем небольшими этапами.
